# Personal Portfolio Website

A responsive personal portfolio website built with Bootstrap 5 — featuring a
home banner, education timeline, project showcase, image gallery, and a
contact section.

## Sections

- **Home** — intro banner with name and title
- **About** — short bio and profile photo
- **Education** — timeline of academic background
- **Projects** — showcase of completed work
- **Gallery** — image portfolio
- **Contact** — a message form for visitors to reach out

## Tech Stack

- **HTML5 / CSS3**
- **Bootstrap 5.1.3** (via CDN)
- **Font Awesome 6** for icons
- **Google Fonts** (Open Sans)

## Project Structure

```
├── index.html
├── css/
│   └── style.css
├── bootstrap.js/
│   └── bootstrap.bundle.min.js
└── img/
    └── (profile photo, favicon, gallery images)
```

## Running Locally

No build step required — it's a static site.

```bash
git clone https://github.com/niloyahme-d/<repo-name>.git
cd <repo-name>
open index.html
```

Or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
